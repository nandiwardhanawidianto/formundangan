# Form Undangan — Royal Wedding Invitation

Proyek Laravel 12 + React/Vite untuk pengisian data undangan secara bertahap dalam Bahasa Indonesia.

Fitur yang disepakati: nomor pesanan Shopee dan WhatsApp pelanggan, akses ulang memakai nomor pesanan, autosave, Isi Nanti, maksimal 3 acara, 10 foto digital masing-masing maksimal 7 MB, notifikasi lonceng admin, pemeriksaan manual, pengajuan ke WhatsApp, ekspor JSON dan JSX.

**Status:** Implementasi awal sedang disusun. Belum layak digunakan untuk pesanan nyata sebelum pengujian dan pengaturan hosting. Jangan unggah file `.env`, kata sandi, atau foto pelanggan ke repositori publik.
